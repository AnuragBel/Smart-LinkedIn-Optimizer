# 🤖 Smart LinkedIn Optimizer

An AI-powered web app that helps new LinkedIn users build a professional profile instantly.

Just enter your role, experience level, and skills — and the AI generates everything for you.

## ✨ Features

- 🏷️ Professional Headline
- 🎯 Career Objective
- 👤 About / Summary
- ⚡ Technical Skills
- 🏭 Industry Knowledge
- 🤝 Soft Skills
- 💼 Experience Description
- 🏆 Achievements
- 📜 Certifications
- 🔗 Custom URL Suggestion
- 💬 Connection Message Template
- 🏢 Top Companies to Follow
- 🔍 Job Titles to Search

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React + Vite + Tailwind CSS |
| Backend | Node.js + Express |
| AI Model | LLaMA 3.3 70B via Groq API |
| Styling | Tailwind CSS |
